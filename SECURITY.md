# Security Policy

## Supported versions

Security updates target latest Marketplace release.

## Reporting a vulnerability

Please report security issues privately by emailing the maintainer or opening a GitHub security advisory if available. Do not publish proof-of-concept exploit details before a fix is available.

## Scope

Markdown Live Server binds to `127.0.0.1` and serves files from selected workspace roots. Treat previewed Markdown as trusted workspace content because raw HTML in Markdown is enabled.
