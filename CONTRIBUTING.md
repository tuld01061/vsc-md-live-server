# Contributing

Thanks for improving Markdown Live Server.

## Local setup

```bash
npm install
npm run compile
```

Use VS Code `Run Extension` launch config or press `F5` to test changes in an Extension Development Host.

## Pull requests

- Keep changes focused.
- Update README or CHANGELOG when behavior changes.
- Run `npm run compile` before opening a pull request.
- Include manual test notes for UI or preview behavior.

## Issues

When reporting bugs, include:

- VS Code version.
- Extension version.
- Operating system.
- Steps to reproduce.
- Expected and actual behavior.
